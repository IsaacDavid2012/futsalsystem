# Futsal Booking System (Auth Starter)

Cinematic login and signup with a Node/Express + SQLite backend.

## Run

1. Install dependencies (already done if you followed setup).
2. Start the server:
   - `npm run dev`
3. Open http://localhost:3000/login.html

## Notes
- Auth uses JWT stored in an HTTP-only cookie.
- SQLite database file is stored in `data/auth.db`.
